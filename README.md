# Welcome Services

Site da Welcome Services, gestora de alojamento local no Porto: uma página de entrada com todas as casas,
filtradas por zona, e uma página própria para três delas.
Site estático (HTML, CSS e JS, sem build): abre `site/index.html` ou publica a pasta `site/`.

- `site/index.html` — a página de entrada: o Porto, a barra de reservas, o catálogo das casas e o mapa «Onde ficar».
- `site/cedofeita-charming-flat/`, `site/porto-cathedral/` e `site/boavista-luxury-villas/` — a página de cada casa.
- `site/assets/` — estilos, scripts e fotografias.
- `netlify.toml` — publica só a pasta `site/`.

Fotografias da região: Wikimedia Commons (créditos no rodapé do site). Mapas: © colaboradores do OpenStreetMap.
